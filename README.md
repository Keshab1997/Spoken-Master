## ✨ Features

- 🎯 Structured speaking practice
- 📚 Lessons to build vocabulary & fluency
- 📈 Track your daily progress
- 🌐 Clean, distraction-free UI
- ⚡ Fast & lightweight web experience

## 🛠️ Built With

- **TypeScript — core language**
- **React — interactive UI**
- **Vercel — one-click deployment**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Keshab1997/Spoken-Master.git
# Install dependencies
npm install
# Start the app
npm run dev
```

🔗 **Try it live:** [https://spoken-master.vercel.app](https://spoken-master.vercel.app)
